# Sunscorch Depot art sources

- `References/CC0_Corrugated_Material_Reference.png` was retrieved from the
  **3DTextures.me** corrugated-material collection on 2026-09-26 as visual
  research for the depot's weathered corrugated panels. The result identifies
  the source as a free CC0 seamless texture: <https://3dtextures.me/tag/corrugated/>.
- The four `Textures/SD_*_Albedo.png` files are original, tileable albedo maps
  generated for this project. They are deliberately free of logos, text, and
  third-party map imagery. They are imported as repeatable sRGB game textures.

No Call of Duty map art or screenshots are shipped as level textures. The map
is an original three-lane desert depot designed around the gameplay scale of
the included player prefab.
