# Research notes — rules

**No feature is implemented before its note exists here.** Each note records:
1. What it is (the real COD behaviour).
2. Exact parameters (numbers, timings, costs).
3. Sources (primary first).
4. Observed UX/visual reference.
5. Our decision + deviations (we target low-poly, smooth, fun, "COD-ish", not photoreal).
6. Acceptance test.
